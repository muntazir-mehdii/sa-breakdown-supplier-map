# Breakdown supplier map (preview)

A single-page preview: map of South Africa with supplier pins, breakdown location by address, pasted WhatsApp/Google Maps pin or map tap, and the 3 closest suppliers by road with distance and drive time.

- Map: Leaflet with CARTO/OpenStreetMap tiles. Address search: Nominatim. Road distance and routes: OSRM public server.
- Supplier rows are sample data inside the page, standing in for the Google Sheet. Names and numbers are made up.
- Sign-in is a preview only (approved list stored in the browser). The real build uses Google sign-in checked on the server.
